# ramidaud.com

Personal site for Rami Daud. Plain HTML, CSS and JS, hosted on GitHub Pages.

- Design system: `assets/css/e1.css` (home and shared) and `assets/css/e1-pages.css` (inner pages); behavior in `assets/js/e1.js`
- Writing index: `assets/data/writing.json` feeds the Writing page, the home mission log and the Latest dispatch card

- `index.html` home page, `cv/` About and CV
- `assets/img/photos/` web exports only: sRGB, 2400 px long edge, about 300 to 500 KB
- Full-resolution files, drafts and Resolve exports live in `../ramidaud-source/`, never in this repo
- Video is hosted on Vimeo; only a short muted hero loop (under 10 MB) goes in `assets/video/`

Preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000
