              What's real in this demo
              
    
              
      
              Bursts, ratings, filters, readinessReal logic, run in your browser on these 26 frames.
              
      
              UCM style checksReal. The same rule file the Mac app uses (ucm-style.json), run on whatever you type.
              
      
              "Sharpest of" picksReal, but simple: an edge-contrast score measured on these web exports. The Mac app uses Apple Vision.
              
      
              Captions, alt text, keywordsSample drafts written ahead of time. In the app they come from Apple's on-device model.
              
      
              Writing to XMP and LightroomShown, not done. The app writes these exact fields with ExifTool and reads them back.
              
      
              Airtable, faces, ingestLeft out. No uploads, no network calls, no names.
              
    
              
    
              Proof is a native Mac app for university photographers. Read the case file for why it exists and the rules it follows.
